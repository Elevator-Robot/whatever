# EDC System

Electronic Data Capture (EDC) system built with Next.js, featuring:
- Progressive Web App (PWA) capabilities
- Tailwind CSS for styling
- Accessibility features
- Form builder and data capture functionality

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- **Form Builder**: Create custom data capture forms
- **Data Management**: Capture, validate, and store data
- **PWA Support**: Offline capabilities and installable app
- **Accessibility**: WCAG compliant interface
- **Responsive Design**: Works on all device sizes

## Technology Stack

- Next.js 15 with App Router
- TypeScript
- Tailwind CSS
- PWA capabilities with next-pwa
